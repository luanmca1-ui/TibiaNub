# Imagens dos itens

Adicione aqui as imagens dos itens em formato PNG, JPG ou WEBP.

O nome do arquivo deve ser o mesmo utilizado no campo imageUrl dos equipamentos.

Exemplo:
- imageUrl: /images/items/steel-helmet.png
- arquivo: public/images/items/steel-helmet.png

Use apenas imagens próprias, autorizadas ou permitidas por licença.
Não baixe automaticamente imagens do TibiaWiki ou Tibia.com.

Se uma imagem não existir, o portal exibirá um placeholder automaticamente.
